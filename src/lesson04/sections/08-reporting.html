08Reporting a demographic analysis

A PSMC curve is only as good as the choices behind it: which reads, which calls, which mask, which time pattern, which mutation rate and generation time. A reader cannot judge the curve, or redraw it with a better mutation rate, unless every one of those choices is written down. This section lists what a methods paragraph must say, how to draw the figure, which sentences a single genome cannot support, and which files to share. The tool at the end builds a methods paragraph from your choices and marks what is missing.

1. What the methods paragraph must state

Each item below changes the curve. If it is missing, a reader cannot tell whether a bump is history or a by-product of your settings. The right-hand column says where in this lesson the reason is explained.

ItemWhat to writeWhy it matters
The animalSpecies, sample or voucher ID, sex, one individual.A male's X is single-copy and looks like one long homozygous stretch (s02). One individual stands for its population only if that population was not structured (s01).
ReadsTechnology and chemistry (Illumina PE150, PacBio HiFi, ONT R10.4.1 and basecaller model), mean depth on the autosomes.Depth decides how many heterozygous sites are missed. Nadachowska-Brzyska et al. (2016) found that curves of the same flycatchers agreed only from a mean coverage of about 18× and with no more than 25 % missing data.
Reference and mappingWhich assembly (own or a relative's), mapper with version and preset.Reads that map poorly in divergent regions remove heterozygous sites there.
Caller and filtersCaller, version and model; which calls were kept (PASS, biallelic SNVs only, allele fraction window such as 0.3–0.7).Filters alone can change the heterozygosity several-fold, and the recent part of the curve with it (s02, s06).
Callable maskThe rule (depth bounds, MAPQ cut-off, excluded contigs) and the result: callable bases and their share of the autosomes analysed.Unmasked low-depth regions look homozygous and push the curve down; high-depth regions (collapsed repeats) add false heterozygotes. The PSMC README recommends a minimum depth of a third of the average and a maximum of twice the average.
Sex chromosomes and organellesWhich contigs were removed and how they were recognised.In the heterogametic sex the X or Z has no heterozygous sites at all (lesson 3, s09).
PSMC inputBin size (100 bp unless you changed it) and how bins were coded.The bin size enters the scaling formula directly (s04).
PSMC runVersion and the full command line, including -N -t -r -p.The -p pattern decides how many time windows the curve has. The psmc program's built-in default (4+5*3+4 in the current source) is not the README's 4+25*2+4+6, so "default settings" is ambiguous: always write the pattern out.
Pattern rerunsThe extra patterns you ran, e.g. -p "2+2+25*2+4+6" and "1+1+1+1+25*2+4+6", and whether the curve changed.Hilgers et al. (2025) found false recent peaks with the README pattern in more than 200 published PSMC curves and wrote: "If a peak is only observed with the default parameter setting, it is likely an artifact" (s06).
BootstrapsHow many, and the segment size the input was cut into. splitfa cuts pieces of 500,000 bins by default (50 Mb at 100-bp bins) and leaves a sequence whole if it is shorter than 1.5 times that, so in a contig-level assembly most contigs are single segments.Shows how much the curve depends on which parts of the genome were used. It does not test the calls, the pattern or the mutation rate.
Mutation rate μ and generation time gThe values, their units (per site per generation, or per year), and a source for each. If either is a placeholder, say so.Every year and every population size on the axes is proportional to 1/μ; years also scale with g (s04).
PlottingWhich iteration was plotted and the axis limits; plotting script and version.PSMC refines its estimate in rounds (iterations, set by -N). psmc_plot.pl plots iteration 20 unless told otherwise (-n 20), starts the time axis at 10,000 (-x; its help text says generations, but it is applied to the plotted axis, in years when -g is given), and uses human values (-u 2.5e-08, -g 25) unless you give your own.
Sensitivity tests and the trusted time rangeWhat else you ran (other call sets, read halves, masks, a second method) and the time range you interpret.The old part of a single-genome curve is usually reproducible; the most recent part is not (s03, s06).
Simple explanation with examples: why a reader needs all of this

Think of the curve as a reading on an instrument that has several dials. A paper that prints the reading without the dial positions cannot be checked or compared. Three common cases:

Paper A: "PSMC (default settings), μ = 2.5e-8, g = 25" ^ which pattern? ^ these are psmc_plot.pl's human values; source for a vole? Paper B: "Illumina 12x, bcftools, PASS" ^ below ~18x: heterozygous sites lost, Ne too low (Nadachowska-Brzyska 2016) Paper C: "100 bootstraps confirm the bottleneck at 20 kya" ^ bootstraps resample the genome; they do not test the pattern, the calls or μ

With the dial positions written down, a reader can redo the scaling with a better μ in two minutes, or see that a peak sits exactly in the window the default pattern is known to distort.

2. Drawing the figure

  • Log time axis. PSMC's time windows are spaced on a logarithmic scale (the source sets them as α(eβk − 1)), so a linear axis squeezes everything except the oldest windows into the left edge. A log axis for Ne is usual too.
  • Units in the axis labels, μ and g in the caption. "Years ago (μ = 5.4×10⁻⁹ per site per generation, g = 1 year)". Or draw the curve in scaled units, which need neither: time as pairwise divergence d = t × θ₀ / s and size as θ = λ × θ₀ / s (PSMC README, appendix I; θ₀ is the scaled mutation rate PSMC estimates, s the bin size). A reader then multiplies by their own μ.
  • Bootstraps as thin lines behind the main curve, so the reader sees where they spread.
  • Several μ values (or a stated range) when μ is uncertain. On log–log axes a different μ slides the whole curve along a diagonal, without changing its shape.
  • Mark the time range you do not interpret, rather than cutting it off silently or letting the most recent window run up the y axis.
  • A title inside the image and a colour legend above the plot. Figures get copied into slides and reviews without their captions. Keep one colour per species in every figure of the paper.

3. What a single-genome curve cannot support

The curve is a smoothed estimate of how fast the two copies of the genome found common ancestors at each time in the past, its IICR. It equals the effective population size (Ne) only if the population was one randomly mating unit; subdivided populations of constant size can produce curves that look like growth or decline (Mazet et al. 2016; Chikhi et al. 2018). Write accordingly.

Do not writeWhy notWrite instead
"The population declined 18,500 years ago."Times come from discrete windows and scale with 1/μ and with g, and both are uncertain for most species (s04)."A decline between about 15 and 25 thousand years ago at μ = …, g = …; between … and … over the μ range shown."
"About 10,000 animals lived then."Ne is not a census, and under population structure even Ne is not what the curve shows."Ne (read from the inverse coalescence rate, assuming one panmictic population) fell to about 10,000."
"The Last Glacial Maximum caused the decline."A coincidence in time, on a time axis that moves whenever μ or g change. Structure changes can produce the same shape."The decline overlaps the Last Glacial Maximum under our scaling." Claim a cause only with independent evidence: fossils, other species scaled the same way, or a fitted model with and without structure.
"Ne increased again in the last 5,000 years."Few coalescences happen that recently; bootstraps spread widely, and the first window is where the default-pattern artefact sits (for human data Li & Durbin 2011 wrote that "more recently than 20 kya ... few recombination events are left")."The most recent ~10,000 years are not resolved by this analysis."
"The species split 1.2 million years ago, where the curves separate."Two single-genome curves can separate long after the split, or before it under structure (s07).Use a method built for divergence (hPSMC with calibration simulations, BPP) and report it as in s07.
"100 bootstraps confirm the bottleneck."Bootstraps resample segments of the same genome. They are blind to call errors, the time pattern and μ."The feature is present in all bootstraps, in both pattern reruns and in the read-half replicate" (list what you actually ran).

4. Sharing inputs and outputs

The reads go to a public archive (lesson 2, s13). That is not enough to redo a PSMC, because the calls, the mask and the settings are where analyses differ. Share these small files as well, in a general data repository with a DOI (for example Zenodo or Dryad):

PSMC input (.psmcfa)
One character per 100-bp bin, so about 25 MB for a 2.5-Gb genome before compression. With it, anyone can rerun PSMC with other patterns.
Callable mask (BED)
The regions counted as callable, and the list of excluded contigs.
Heterozygous calls (VCF)
After filtering, with the filter command. A gVCF is better if you have it.
PSMC outputs (.psmc)
Main run and every bootstrap. The file header (MM lines) records the PSMC version, the pattern and the number of iterations, so it documents itself.
Plotted numbers
The time and Ne table behind each line. psmc_plot.pl -R keeps the tables it draws from (prefix.N.txt); without -R it deletes them.
Commands and scripts
Every command with tool versions, and the script that converts to years with μ and g.
# keep the plotted tables and give your own mu and g (psmc_plot.pl defaults are human: -u 2.5e-08 -g 25)
# -R keeps prefix.*.txt; -x 0 lets the time axis start where the data start instead of at 10,000 years
utils/psmc_plot.pl -R -u 5.4e-09 -g 1 -x 0 -T "Species, PSMC, mu 5.4e-9, g 1 yr" prefix combined.psmc

# the header of every .psmc file records version, pattern and iterations

The species A-like example in the builder follows what our project log records, with depth and callable length rounded to toy values: ONT reads, Clair3 with model r1041_e82_400bps_sup_v500, heterozygous SNVs kept at PASS and allele fraction 0.3–0.7, a mask of MAPQ ≥ 10 and depth bounds of about half to twice the mean, the half-depth X-class contigs excluded, 100-bp bins, PSMC 0.6.5-r67 with -N25 -t15 -r5 -p "4+25*2+4+6", 20 bootstraps and both split-first-window reruns. μ = 5.4×10⁻⁹ and g = 1 year are placeholders, not values established for this species; changing μ to 7.86×10⁻⁹ moves every time and size by a factor of 1.46 (s04). The curve is reproducible across call sets and read halves for the old part only; the most recent intervals are not interpretable. The fields the builder still flags in this preset (the exact Clair3 version, the mapper, the plotted iteration, the bootstrap segment size) are ones the log we quote does not give, and the R10.4.1 chemistry is inferred, not confirmed by the provider. That is the point: write these down while you run the analysis, not when you write the paper. Our own figure rule: a title inside every image, a colour legend above the plot, and the same colour for each species in every figure (species A grey, the relative teal).
