09A viewer for your own PSMC and MSMC files

The figures so far were toys. This section is a working tool: it reads the result files of PSMC and MSMC or MSMC2 from your computer, draws them together, and lets you give every file its own mutation rate and generation time. Use it to look at a finished run without installing gnuplot, to put two species with different constants on one plot, and to see at once how much a curve moves when the constants change (s04).

What it reads

.psmc
The output of psmc (s03). The viewer takes θ0 from the TR line and tk and λk from the RS lines of one iteration, the last one in the file unless you ask for another.
main run + bootstraps
A file made by joining the main run and the bootstrap runs (cat main.psmc round-*.psmc > combined.psmc, s03). The first run is drawn as a thick line, the others as thin lines of the same colour.
.final.txt
The result table of MSMC or MSMC2 (s05): columns time_index, left_time_boundary, right_time_boundary and one or more lambda columns. A two-population file with three λ columns can also be drawn as the relative cross-coalescence rate of s07.

The files are read by your browser on your own computer. Nothing is sent anywhere, so unpublished results are safe to open.

Tool

Plot and rescale result files

The page opens with three invented toy files in the real file layouts (they are not the output of any run) so that there is something to try. Choose your own files to replace them. μ is the mutation rate per site per generation and g the generation time in years; type a new value in the table and the curve is redrawn.

showcurvefilerate per generationg, yearsbin s

SVG is the format to give to a journal or to edit; PNG is a picture for slides. The TSV table holds every drawn curve as years and size with the μ and g that were used, so that others can redraw it (s08).

How the numbers are scaled

The viewer applies the formulas of s04, in the same way as the plotting scripts that come with the programs.

PSMC: N0 = θ0 / (4 μ s) years ago = 2 N0 tk g Ne = λk N0
MSMC: years ago = left_time_boundary × g / μ Ne = 1 / (2 μ λ)
cross-coalescence = 2 λ01 / (λ00 + λ11)

It differs from psmc_plot.pl in four ways, all of them choices of display:

  • It draws the last iteration in the file. psmc_plot.pl draws iteration 20 unless you give -n (s03). Type a number in "PSMC iteration" to pick another.
  • It does not cut the recent end of the time axis; psmc_plot.pl starts at 10,000 by default (-x). Set "years from" yourself.
  • Sizes are plain numbers of individuals, not units of 104.
  • It applies no correction for missed heterozygous sites (-N and -M of psmc_plot.pl, s04). Low-coverage runs need that correction before they are compared.

A step is drawn from the start of each time interval to the start of the next, so each curve ends at the start of its last interval. On a logarithmic time axis the first interval, which starts at zero, runs in from the left edge.

Simple explanation with examples: two files, two rulers

Every file holds numbers in model units. The viewer multiplies them by a ruler built from μ and g, and each file may have its own ruler. Take the PSMC example of s04 (θ0 = 0.08 per 100-base bin) and one MSMC2 row with a left time boundary of 0.00001 and λ = 2000:

PSMC, μ = 5.4e-9, g = 1: N0 = 0.08 / (4 × 5.4e-9 × 100) = 37,037 RS row with t = 0.5, λ = 1.5: 2 × 37,037 × 0.5 × 1 = 37,037 years, Ne = 1.5 × 37,037 = 55,600 MSMC2, μ = 5.4e-9, g = 1: 0.00001 × 1 / 5.4e-9 = 1,852 years, Ne = 1 / (2 × 5.4e-9 × 2000) = 46,296 the same MSMC2 row for a species with g = 3 years: 0.00001 × 3 / 5.4e-9 = 5,556 years, Ne = 46,296 (only the time moves)

Try it in the tool: change g of one toy file from 1 to 3 and its curve slides to the right without changing height; double its μ and it moves left and down by half. If two species really differ in generation time, giving each file its own g is the honest way to draw them on one time axis. If you do not know the constants, say so in the figure legend (s08).

What the viewer cannot tell you. It draws whatever the file holds. Whether a peak is real is decided by the checks of s06, and the default μ = 5.4 × 10-9 and g = 1 are the placeholders of this lesson, not values for your species.
