1A methyl group sits on a C and the letters stay the same

Some cytosines (C) carry a small chemical tag, a methyl group. The sequence does not change: the mark sits on top of the letters, which is why it is called epigenetic. It sits mostly at a CpG, a C followed directly by a G. Click a CpG to add or remove the mark.

Whatever you click, the letters stay the same. To see the mark, a machine needs a different measurement (block 6).

2Counting reads at one site gives a percentage

A long read is one DNA molecule, so at one CpG it shows a mark or no mark. Stack many reads over the same CpG and count: the share of reads with the mark is the methylation level of that site. Each row is one read; each column is one CpG.

Filled circle: marked. Open circle: not marked.

3More reads make the percentage more trustworthy

Ten reads are only a small sample, so another ten would give another percentage. Below, one site with a true level of 60 % is measured 40 times, with 4, 10, 40 and 160 reads. Each dot is one measurement.

Dashed line: the true level, 60 %.

4Unsure calls are set aside, so fewer reads count

The machine gives each read a probability of "methylated", not a yes or no. Near 0 or 1 is a confident call; near the middle is unsure. The pass threshold is the minimum confidence a call needs; calls below it are not counted. The same 20 reads are shown three times.

Each dot is one read, placed by its probability. Filled: methylated. Open: unmethylated. Grey: set aside.

5An average of 50 % can hide two parental copies that differ completely

An animal has two copies of each chromosome. At some places one copy is methylated and the other is not, and the average of all reads says "50 %", which describes neither copy. A read shows its copy by a nearby SNP. Sorting the reads by that base gives a level for each copy.

Each row is one read, with the base of its SNP at the left. Left region: the copy with A is methylated, the copy with G is not. Right region: the copies do not differ.

6Only a file that keeps the signal or the calls can give a level

A methylated C is still read as C, so the letters cannot show the mark. The machine measures a signal, and a program turns it into a probability per CpG. If the provider hands over only the letters (FASTQ), the mark is lost. Below, the same four reads are stored in three ways.

When ordering a run, ask the provider to keep the raw signal or a BAM with modification tags. The probabilities here are invented.
