1A sequencer reads pieces, not whole chromosomes

A chromosome is one very long DNA molecule, a chain of four kinds of bases: A, C, G and T. No machine can read it from end to end. We break the DNA of many cells into pieces, and the sequencer reports the order of bases in each piece. One such result is called a read.

2More reads cover more

Reads land at random, so some places get many and others none. Each bar below is one read, stacked over the place it came from. Where nothing overlaps the next read, the assembly stops, and a piece built from joined reads is called a contig. Coverage says how many times an average place was read. The four panels below are the same genome with more and more reads. To keep the picture readable, the genome here is simplified to one chromosome of 1,000 bases; a real genome has many chromosomes, and each is assembled the same way.

Two reads are joined only if they overlap by at least 10 bases. A contig ends for one of two reasons: no read covers the next bases at all (red dashed box: we have no sequence there), or the next read does overlap, but by fewer than 10 bases (black mark: the two contigs touch, but the assembler cannot be sure they belong together, so it keeps them apart).

3An overlap only helps if it occurs in one place

The assembler has only the reads, in a pile, with no places. Two reads belong together when they overlap: a stretch at the end of one is the same as a stretch at the start of the other. The overlap has no direction; which read comes first follows from where the shared letters sit, not from which read we picked first. Below, we start from read A and look for the read that continues it to the right (looking to the left works the same way). The computer looks through the pile for reads that start with A's last letters. Each read it finds is drawn under the place it really came from, which the computer cannot see: only one of them is the real next read.

A repeat is the same run of letters in two places of the chromosome (pink, underlined). Every read here matches the chromosome exactly; no read is wrong. The question is only which read continues A. Green: the one that does. Orange: look-alikes, real reads from other places that start with the same letters.

4Only a read longer than the repeat crosses it

Much of an animal genome is made of sequences that occur many times. Inside a repeat every overlap occurs in each copy, as you just saw, so more reads do not help. The only way across is a read that starts before the repeat and ends after it. This genome has one 60-base repeat in two places, and every read length here has the same coverage, 20×.

5Assembling alone, or against a relative

There are two ways to use reads. De novo assembly joins reads to each other by their overlaps (block 3) and needs nothing else. Reference-based work places each read where it matches the finished genome of a related species. Below, the same reads from our animal are used both ways. The relative's chromosome is like ours, except for a few single letters and one stretch that only our animal has.

Gaps (–) in the relative's row only line it up with our chromosome. Against the relative, a read is placed where it matches with at most one different letter; a read that matches nowhere, or equally well in two places, is set aside. De novo, two reads are joined when the end of one equals the start of the other over at least 5 letters, as in block 3. 6How we judge the result

A good assembly has few, long pieces. The usual number is N50: sort the contigs from longest to shortest, add up their lengths until you reach half of the assembly, and read the length of the contig where you stopped. A larger N50 means longer pieces. Length is not everything, so we also check that the genes every related animal has are present and whole. That check is called BUSCO.
