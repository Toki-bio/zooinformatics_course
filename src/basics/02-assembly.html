1A sequencer reads pieces, not whole chromosomes

A chromosome is one very long DNA molecule, a chain of four kinds of bases: A, C, G and T. No machine can read it from end to end. We break the DNA of many cells into pieces, and the sequencer reports the order of bases in each piece. One such result is called a read.

What the sequencer gives us: the same reads, in random order, with no place attached.

The chromosome, and each read drawn under the bases it was copied from, are shown here only so that you can see where each read came from. In real work we never see it: we get the list of reads and nothing else. Assembly means rebuilding the chromosome from that list.

2More reads cover more

Reads land at random, so some places get many and others none. Each bar below is one read, stacked over the place it came from. Where nothing overlaps the next read, the assembly stops, and a piece built from joined reads is called a contig. Coverage says how many times an average place was read. These four stacks are the same genome with more and more reads.

Grey bars: reads. Blue and purple bars under each stack: the contigs, one colour change for each break. Red: places no read covers. Two reads are joined only if they overlap by at least 10 bases.

3An overlap only helps if it occurs in one place

We know two reads belong together because the end of one has the same bases as the start of the other. But a short run of bases occurs in many places by chance, so a short overlap proves nothing. The overlap has to be long enough to occur in one place only. Here the computer really searches a 600-base genome for the end of one read. Each line below the genome is a read that could fit at that place.

4Only a read longer than the repeat crosses it

Much of an animal genome is made of sequences that occur many times. Inside a repeat every overlap occurs in each copy, as you just saw, so more reads do not help. The only way across is a read that starts before the repeat and ends after it. This genome has one 60-base repeat in two places, and every read length here has the same coverage, 20×.

5Assembling alone, or against a relative

There are two ways to use reads. De novo assembly joins reads to each other and needs nothing else. Reference-based work places each read on the finished genome of a related species. The second is easier and cheaper, but it can only show what the relative has too.

6How we judge the result

A good assembly has few, long pieces. The usual number is N50: sort the contigs from longest to shortest, add up their lengths until you reach half of the assembly, and read the length of the contig where you stopped. A larger N50 means longer pieces. Length is not everything, so we also check that the genes every related animal has are present and whole. That check is called BUSCO.
