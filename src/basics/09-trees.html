1Name order on the page means nothing

A phylogenetic tree shows which species share a more recent common ancestor. The tips are the species and the nodes are the ancestors where lines split. Any node can be turned half-way round and the tree stays the same. So neighbours on the page need not be close relatives; read closeness from the nodes.

2The root changes the groups

DNA shows how similar the tips are, not which way time runs. The root is the oldest node, placed using an outgroup, a lineage known to have split off first. A clade is an ancestor with all its descendants, so the clades depend on the root.

3A shared change joins two species

Four species can be joined in three ways. Each column of the aligned DNA is a character. If A and B share a base that C and D lack, joining A with B explains it with one change; joining A with C needs two. Parsimony picks the tree with the fewest changes in total.

4Long branches can mislead

Two distant relatives that both changed a lot can end up with the same base by chance, since there are only four bases. Parsimony reads this as shared inheritance: long-branch attraction. Below, the true tree pairs A with B and C with D.

5Support means repeatable, not true

A method always returns a tree. The bootstrap checks how stable a branch is: it draws columns of the alignment at random, so some come twice and others not at all, builds a tree each time, and counts how often the branch appears.

6A gene tree can differ from the species tree

A species tree is the order in which populations split; a gene tree is the history of one stretch of DNA. If two gene copies do not meet before the older split, any two of three lines can meet first. This is incomplete lineage sorting. Time is in coalescent units.
