Zooinformatics

Practical genomics for zoologists: from raw sequencing reads to assembled and checked genomes. Each lesson builds the ideas from toy examples and interactive figures, then gives the tools and commands to run on real data.

Format self-paced web lessonsLevel no bioinformatics background assumedPractice commands for Linux servers and Galaxy

How to use the lessons

  • Take the lessons in order. Each starts with an introduction and an "order of work" list; every term is defined where it first appears, and dotted terms show an explanation when you hover over them.
  • Open the collapsed "Simple explanation" boxes when a step is not obvious; they work through small examples.
  • The figures are simulated teaching examples. The commands are meant for real data; check them against the tool versions you have installed.

How the lessons are made

  • Checked against the sources. Defaults, options, file names and resource figures come from each tool's own documentation and, where needed, its source code, at the version named in the lesson. Each section's sources are listed in the course repository.
  • Our own data as examples. "In our projects" boxes show what happened in the lab's genome projects on small mammals (desmans among them), including what went wrong.
  • Reviewed as a whole. Each lesson is read end to end for undefined terms and contradictions, and every interactive figure is tested in a browser on desktop and phone widths.
