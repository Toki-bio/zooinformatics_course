Lesson 8 · the basics

Searching Sequences: the basics

The main ideas in a few short blocks, with things to try. The full lesson has the details, commands and sources.

1An index beats re-reading for many queries

A query is the sequence you look for; the target is the sequence you look in, such as a genome. A scan reads the whole target for every query. An index is a lookup table built once, so each query goes straight to the right place. The page counts the places each method examines.

2Short words match everywhere, long words match once

An index is built from words: every run of k bases. Each dot is a word of the query found in the target (across: place in the target, down: place in the query). A real match is dots on one straight line. Change k and watch the other dots.

3A score tolerates differences

An alignment lines two sequences up and gives a score: points for equal bases, a penalty for different ones. Below, one query is aligned to copies with more and more changes, and to an unrelated sequence.

Green: same base. Red: different. Bar: score. Dashed line: best score of 200 unrelated sequences.

4A seed can miss a diverged copy

Fast tools use an exact word as a first test and call it a seed. A copy with no seed is never looked at again. Divergence is the share of bases that differ. The bars show how many copies each word length finds.

Each bar: share of 300 simulated copies with at least one seed.

5Extending a seed tells real from chance

A seed is only a candidate. The program extends it: it walks outwards along both sequences, scoring as before, and stops when the score falls well below its best. Here every seed of a changed copy is extended and its final score plotted.

One dot per seed. Green: at the true place. Orange: by chance. Right is a higher score.

6A bigger target needs a higher score

A bigger target has more places where a chance alignment can score well, so the score that counts as real must grow with its size. The lesson expresses this as an E-value. Here a query is aligned to random targets of three sizes and to copies of itself.

Grey: best chance score in a random target. Green: score against a copy. A copy is found when its bar is higher than the grey one.
